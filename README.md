# Rutinim PWA

Bu klasör GitHub Pages için hazırdır.

## Yayınlama
1. GitHub'da yeni bir public repo oluşturun (ör. `rutinim`).
2. Bu klasördeki dosyaların tamamını repoya yükleyin.
3. Repo > Settings > Pages > Build and deployment > Deploy from a branch.
4. Branch: `main`, Folder: `/ (root)` > Save.
5. GitHub Pages bağlantısını Safari'de açın.
6. iPhone'da Paylaş > Ana Ekrana Ekle.

Veriler tarayıcının localStorage alanında cihazda tutulur.
